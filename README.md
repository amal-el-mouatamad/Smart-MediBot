# 🤖 Smart MediBot

### Robot intelligent d’assistance aux personnes âgées

> 🚧 Projet en cours de développement
## 📌 Présentation

Smart MediBot est un projet basé sur l’Intelligence Artificielle visant à concevoir un robot intelligent capable d’assister une personne âgée dans son domicile.

Le robot évoluera dans un environnement 3D simulé représentant une maison intelligente. L’objectif principal est d’aider la personne âgée à gérer ses médicaments, notamment en lui rappelant les horaires de prise et en réagissant à certaines situations.

## 🎯 Problématique

Les personnes âgées peuvent parfois oublier l’heure de prise de leurs médicaments ou oublier si elles ont déjà pris leur traitement.

Dans certaines situations, elles peuvent également avoir besoin d’une assistance rapide lorsqu’un problème survient à domicile.

### Question principale

> Comment concevoir un robot intelligent capable d’assister une personne âgée dans la gestion de ses médicaments et de réagir intelligemment à certaines situations dans une maison virtuelle ?

## 🎯 Objectifs

Le projet vise à :

- Concevoir une base de données pour gérer les patients, médicaments et horaires.
- Mettre en place une gestion des utilisateurs et des droits d’accès.
- Intégrer un robot dans un environnement 3D.
- Permettre au robot de se déplacer dans la maison virtuelle.
- Développer un système de rappel des médicaments.
- Utiliser le Deep Learning pour une fonctionnalité intelligente.
- Développer un système de prise de décision du robot.
- Enregistrer l’historique des prises de médicaments.
- Générer des alertes en cas de situation inhabituelle.

  ## 🔄 Scénario de fonctionnement

1. La base de données vérifie l’horaire du médicament.
2. Python détecte qu’une prise est prévue.
3. MediBot localise le patient.
4. Le robot se déplace vers le patient.
5. Le système analyse la situation.
6. MediBot informe le patient qu’il est temps de prendre son médicament.
7. Le résultat est enregistré dans la base de données.
8. En cas de problème, une alerte peut être générée.
